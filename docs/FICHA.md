Equipo de 2. Complementa la ficha global (`00_global`). El repositorio está vacío. Posible traspaso a un asesor externo al terminar el proyecto.

## Objetivo
Sitio informativo de CECAPI, accesible, que enlace al asistente y a las descargas.

## Tipo y plataforma
Sitio estático (HTML, CSS, JavaScript simples) en GitHub Pages. Sin PHP.

## Contenido base (del prompt del servidor, a confirmar con CECAPI)
CECAPI, calle Jacarandá 1603, col. Valle Florido, CP 34226, Durango; tel. 618 455 0146; horario L–V de 2 a 7 pm. Confirmar cada dato en la reunión.

## Tareas, en orden
1. Contenido y estructura con CECAPI: quiénes son, servicios, contacto, ubicación.
2. Maquetación semántica con encabezados, puntos de referencia, enlace de salto al contenido y texto alternativo en imágenes.
3. Paleta y tipografía acordes a baja visión (contraste suficiente, texto ampliable).
4. Páginas de aviso de privacidad y términos, con versión de audio.
5. Enlaces al asistente web y a las descargas.
6. Pruebas con lectores de pantalla y revisión automática.
7. Caché: archivos versionados.
8. Entrega con documentación para el asesor externo.

## Herramientas
