Editor del contenido del sitio

Aquí se agregan, cambian o quitan los textos, servicios, equipo y fotos de la página de inicio. Nada cambia en el sitio hasta que revisas y pulsas "Publicar cambios".

Conectar

Guardar cambios requiere una llave de GitHub (token) que solo tenga permiso sobre este sitio. La llave se escribe aquí cada vez que se entra; no se guarda en el navegador y se borra al cerrar la sesión o la pestaña.

Cómo obtener la llave
  1. Entra a GitHub con la cuenta que tiene permiso de escritura en el repositorio del sitio.
  2. Abre Settings, Developer settings, Personal access tokens, Fine-grained tokens, y elige "Generate new token". Los nombres de los menús pueden cambiar.
  3. En "Repository access" elige "Only select repositories" y marca solo PaginaCECAPI.
  4. En "Permissions", Repository permissions, pon Contents en "Read and write". No pidas ningún otro permiso.
  5. Elige una fecha de vencimiento corta, genera la llave, cópiala y pégala abajo. GitHub la muestra una sola vez.

Textos del sitio

Frase de presentación, misión, visión, historia, datos de contacto y enlaces. Son textos únicos: se editan, no se agregan ni se quitan.

Servicios

Agrega un servicio nuevo, cambia su horario, ocúltalo por un tiempo o quítalo si ya no se ofrece. Lo que se oculta sigue guardado en el archivo del sitio; es información que no es personal.

    Equipo
