Aviso de privacidad del sitio

Borrador del 28 de octubre de 2026. Debe revisarlo un asesor legal antes de publicarse. No sustituye asesoría legal.

Quién es responsable

Responsable de los datos: pendiente de definir con CECAPI (nombre, domicilio y correo de contacto).

Qué datos se recaban en este sitio

Este sitio es solo informativo. No tiene formularios, no pide cuenta, no usa cookies y no usa herramientas de medición de visitas.

Si cambias el tamaño del texto o el contraste, esa preferencia se guarda solo en tu navegador. No se envía a nadie y la puedes borrar limpiando los datos del sitio en tu navegador.

Quién hospeda el sitio

El sitio se publica con GitHub Pages, un servicio de GitHub. GitHub registra la dirección IP de quien visita el sitio por motivos de seguridad. Ese registro lo hace GitHub conforme a su propia declaración de privacidad.

El asistente y las apps

El asistente de voz y las apps para Android y Windows tienen su propio aviso de privacidad, que se lee antes de usarlos.

Cambios a este aviso

Si este aviso cambia, la nueva versión se publicará en esta misma página con su fecha.
